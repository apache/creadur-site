Release 0.2-SNAPSHOT – xxxx-yy-zz

Type Changes By
Migrate to new doxia 2.x tech stack and improve webpage and add missing Maven documentation and more project reports. Fixes WHISKER-26. pottlinger
Add a download page to the current project webpage. As v0.1 is not officially available anymore only the current SNAPSHOT can be downloaded. Fixes WHISKER-23. pottlinger
Integrate Creadur Whisker into the updated develocity.apache.org instance. Fixes WHISKER-29. Thanks to clayjohnson. pottlinger
Fix build warning and ensure Maven >=3.0.5 is used to build the project. Fixes WHISKER-27. pottlinger
Update Jdom to 2.0.6.1 in order to fix CVE CVE-2021-33813. Fixes WHISKER-20. pottlinger
Upgrade Apache commons-io to fix CVE-2021-29425. Fixes WHISKER-19. pottlinger
Upgrade Apache Commons Collections to v3.2.2 to circumvent CVE-2015-8103. Fixes WHISKER-15. pottlinger
Fixes error during site generation with Java8 and maven plugin version 3.3. Fixes WHISKER-13. dennisl
Change artifactId/goalPrefix of Maven plugin to comply with expected apache-whisker-maven-plugin. Fixes WHISKER-14. dennisl
Update webpage to not load fonts from GoogleFonts and include privacy link in main menu. Fixes WHISKER-22. pottlinger
TODO: before releasing WHISKER-xx: collect all dependabot updates for release 0.2. Fixes WHISKER-xx. Thanks to dependabot. pottlinger
